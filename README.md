# 회의록 · Meeting Notes

회의를 녹음하면 **OpenAI로 받아쓰고, 결정 사항·할 일·미결 질문까지 정리**해 주는 로컬 앱입니다. 내 컴퓨터에서 실행되고 브라우저로 씁니다. Windows·macOS 모두 됩니다.

- **회의실 회의**: 노트북(또는 회의용 마이크) 하나를 테이블 가운데 두면 4~5명 대화를 함께 기록합니다.
- **온라인 회의**: Google Meet·Zoom·Discord 등. 녹음할 때 회의 탭이나 화면을 공유하면 상대방 소리도 같이 기록합니다.
- 녹음 중에는 실시간 자막과 진행 중 회의록이 보이고, **회의 종료**를 누르면 최종 회의록이 만들어집니다.
- 회의록의 모든 항목에 근거 시간이 붙어 있어 누르면 받아쓰기 원문으로 이동합니다. 받아쓰기는 직접 고칠 수 있습니다.

필요한 것은 **OpenAI API 키 하나**입니다.

## 설치

### 가장 쉬운 방법: 코딩 에이전트에게 맡기기

Claude Code나 Codex를 쓰고 있다면 이렇게만 말하세요.

> https://github.com/ksw6895/meeting-notes 받아서 설치해줘

에이전트가 이 저장소의 [`AGENTS.md`](AGENTS.md)를 읽고 설치·빌드를 한 뒤 **“바탕화면에 바로가기를 만들까요?”** 라고 물어봅니다.

### 직접 설치하기

1. **Node.js 22 LTS** 설치 (24 LTS도 됩니다)
   - Windows: [nodejs.org](https://nodejs.org)에서 LTS 설치 파일을 받거나, PowerShell에서 `winget install OpenJS.NodeJS.LTS`
   - macOS: [nodejs.org](https://nodejs.org) 설치 파일 또는 `brew install node@22`
2. 이 저장소를 받습니다. Git이 없으면 GitHub의 **Code → Download ZIP**으로 받아 압축을 풀어도 됩니다.
   위치는 `C:\meeting-notes`처럼 단순한 곳을 권장합니다(바탕화면·문서 폴더는 OneDrive와 동기화되는 경우가 많습니다).
   ```bash
   git clone https://github.com/ksw6895/meeting-notes.git
   cd meeting-notes
   ```
3. 설치하고 실행합니다.
   ```bash
   npm install
   npm start
   ```
   브라우저가 열리면 설정 창에 OpenAI API 키를 붙여넣고 **저장하고 연결 확인**을 누르세요.
4. (선택) 바탕화면 바로가기를 만듭니다.
   ```bash
   npm run shortcut
   ```
   바탕화면에 **회의록**(실행)과 **회의록 종료** 아이콘이 생깁니다. 지우려면 `npm run shortcut -- --remove`.

> 브라우저는 **Chrome 또는 Edge**를 권장합니다. 온라인 회의의 화면 소리 공유는 이 두 브라우저에서 가장 잘 됩니다.

## 사용하기

1. **새 회의** → 이름 입력 → 회의 방식(회의실 / 온라인) 선택. 참가자와 자주 나올 용어를 적어 두면 받아쓰기와 회의록이 더 정확해집니다.
2. **소리 확인**으로 음량 막대가 움직이는지 봅니다. 이 단계는 저장·전송하지 않습니다.
3. 참석자에게 녹음 사실을 알렸다고 체크하고 **녹음 시작**.
   - 온라인 회의는 이때 공유 창이 뜹니다. 회의 탭(또는 화면 전체)을 고르고 **오디오 공유**를 켜세요.
     Windows는 화면 전체 + “시스템 오디오 공유”로 Zoom·Discord 앱 소리도 받을 수 있고, macOS는 Chrome 탭 소리만 받을 수 있습니다.
4. 끝나면 **회의 종료**. 남은 받아쓰기와 최종 회의록을 자동으로 만듭니다.
5. **내보내기**에서 Markdown 회의록, TXT 받아쓰기, 원본 음성(FLAC)을 받을 수 있습니다.

녹음 중에는 앱 탭을 닫지 마세요. 실수로 닫았다면 다시 열어 **녹음 이어가기**를 누르면 됩니다. 이미 저장된 음성은 남아 있습니다.

### 회의실에서 잘 녹음하는 요령

- 노트북이나 마이크를 **테이블 가운데**에 두세요. 한쪽 끝에 두면 먼 자리 목소리가 작게 들어갑니다.
- 노트북 팬 소음이 큰 자리, 에어컨 바로 아래는 피하세요.
- 이 앱은 누가 말했는지 자동으로 구분하지 않습니다. 대신 대화 중에 “지민 씨가 맡아 주세요”처럼 **이름을 부르면** 회의록 할 일 표의 담당자로 들어갑니다.

## 사용하는 모델과 비용

| 용도 | 모델 | 요금 (2026-11 기준) |
|---|---|---|
| 정밀 받아쓰기 (30초 단위) | `gpt-transcribe` | 분당 약 $0.0045 |
| 실시간 자막 (설정에서 끌 수 있음) | `gpt-live-transcribe` | 분당 약 $0.017 |
| 회의록 (실시간·최종, 각각 선택) | `gpt-6.1-terra` 기본 · `gpt-6-luna` · `gpt-6.1-sol` | 토큰당 |

2시간 회의 대략치: 받아쓰기 $0.54 + 실시간 자막 $2.04 + 회의록 $0.5 안팎 ≈ **$3 정도**입니다. 비용 대부분은 실시간 자막이라, 자막이 필요 없으면 설정에서 끄면 약 $1로 줄어듭니다.

진행 중 회의록은 회의 초반 2분마다, 길어지면 최대 5분 간격으로 갱신됩니다. 이미 보낸 받아쓰기 부분은 OpenAI 프롬프트 캐시로 할인 요금이 적용됩니다. 앱이 호출할 때마다 실제 사용량을 로컬 원장(`usage_ledger`)에 기록합니다.

## 개인정보와 저장 위치

- 음성·받아쓰기·회의록은 모두 **이 컴퓨터의 앱 데이터 폴더**에 저장됩니다. 저장소 폴더를 옮기거나 새로 받아도 기록은 그대로입니다.
  - Windows: `%LOCALAPPDATA%\MeetingNotes` · macOS: `~/Library/Application Support/MeetingNotes` · Linux: `~/.local/share/meeting-notes`
  - 다른 곳에 두려면 `.env`에 `MEETING_NOTES_DATA_DIR=경로`
- OpenAI에는 음성(받아쓰기용)과 받아쓰기 문장(회의록용)이 전송됩니다. 회의록 요청은 `store: false`로 보냅니다.
- API 키는 앱 데이터 폴더의 `secrets.json`에 저장되고 화면·로그에 다시 표시되지 않습니다. 저장소 폴더의 `.env`에 `OPENAI_API_KEY=...`를 두면 그 값을 우선 사용합니다.
- 서버는 `127.0.0.1`에서만 열립니다. 같은 와이파이의 다른 기기에서는 접속할 수 없습니다.
- 녹음 전 참석자에게 녹음·전사 사실을 알리세요. 앱은 확인 체크 없이는 녹음을 시작하지 않습니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 마이크 권한 오류 | 주소창 왼쪽 자물쇠(사이트 설정) → 마이크 **허용**. Windows는 설정 → 개인 정보 → 마이크에서 브라우저 접근도 허용 |
| 온라인 회의 상대방 소리가 안 들어감 | 공유 창에서 **오디오 공유** 체크를 켰는지 확인. macOS는 회의를 Chrome 탭에서 열어야 합니다 |
| 받아쓰기 실패 표시 | 설정에서 키를 다시 저장하면 실패한 구간부터 다시 받아씁니다. 원본 음성은 지워지지 않습니다 |
| `npm install` 중 better-sqlite3 빌드 오류 | Node가 LTS(22 또는 24)인지 확인하세요. 최신 홀수 버전은 미리 빌드된 파일이 없을 수 있습니다 |
| 받아쓰기 일부 구간이 끝내 실패 | 나머지 내용으로 최종 회의록을 만들고, 빠진 구간을 요약 끝에 알려 줍니다 |
| 앱이 안 열림 | 앱 데이터 폴더의 `logs/server.log` 확인. 다른 프로그램이 4310 포트를 쓰면 `.env`에 `PORT=4320` |
| 완전히 끄기 | 바탕화면 **회의록 종료**, 앱 설정의 **앱 종료**, 또는 `npm run stop` |

```bash

npm test        # 테스트
npm run build   # 화면 빌드
npm run typecheck
```

구조: `server/`(Fastify · SQLite · 오디오 저널 · 전사 큐 · 회의록 작업), `src/`(React 화면 · 브라우저 녹음), `scripts/`(실행·종료·바로가기).
